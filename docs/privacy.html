slio-git Privacy Policy

slio-git is a Git client that runs on your computer.

What we collect

Nothing. slio-git does not create an account and does not send repository contents, paths, or identifiers to a slio-git server.

What stays on this computer

Settings, recent-project bookmarks, an optional imported SSH key bookmark, and commit identity fields are stored in the app container.

Network

  • Git fetch, pull, and push talk only to remotes you configure.
  • AI commit messages are off by default. If you enable them, slio-git sends the staged diff and recent log to the API URL you enter.
  • The Mac App Store build does not check GitHub Releases. Updates come from the App Store.

Permissions

macOS folder access is used only for repositories and files you select. The App Store build does not read ~/.ssh or your global Git config unless you import a key or fill in name and email in Settings.
